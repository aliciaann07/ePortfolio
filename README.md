# ePortfolio



## Professional Self-Assessment

Completing the Computer Science program and developing my ePortfolio has helped me recognize how much I have grown as a software engineering student and future computer science professional. When I began the program, I was mainly focused on learning how to write code that worked. Through my coursework, I learned that successful software development also requires problem-solving, planning, testing, security, communication, and understanding the needs of the people who will use the final product. These experiences shaped my goal of becoming a software engineer or full-stack developer who creates practical, reliable, and user-focused applications.

Communication and collaboration have also become important parts of my professional skill set. Although many of my projects were completed independently, discussion posts, peer responses, project documentation, code reviews, and instructor feedback taught me how to communicate technical ideas to different audiences. I learned to consider stakeholder requirements, explain my decisions clearly, and use feedback to improve my work. I also participated in a mock Scrum environment, which helped me understand how different team roles work together to meet shared project goals. These skills are important because developers must be able to work with team members, clients, managers, and users who may have different levels of technical knowledge.

My coursework provided experience across several major areas of computer science. I worked with data structures and algorithms such as binary search trees, vectors, maps, queues, sorting, searching, and traversal. In software engineering and database courses, I designed applications, improved user interfaces, used SQLite and MongoDB, developed CRUD functionality, and connected stored data to user-facing systems. Outside of the artifacts in this portfolio, I also completed coursework involving full-stack development, APIs, software testing, debugging, documentation, and secure coding. These experiences taught me that security must be considered throughout development through practices such as input validation, protecting sensitive data, and identifying possible vulnerabilities.

The artifacts in this ePortfolio demonstrate how these skills work together. The Weight Tracking Mobile App represents software design, mobile development, and database integration. The Advising Assistance Program demonstrates algorithmic thinking and the use of data structures to organize and process course information. The Client-Server Development project demonstrates MongoDB integration, CRUD operations, and dashboard-based data retrieval. Together, these artifacts show my ability to evaluate existing code, improve functionality, solve technical problems, and clearly communicate the decisions behind my work.

## Enhancement One: Software Design and Engineering

For Enhancement One, I improved my CS 360 Weight Tracking Mobile App by adding a workout history feature. This enhancement allows users to log workout activity, including the workout date, exercise name, duration, and calories burned. The app was also updated to store workout records in SQLite and support adding, updating, deleting, and viewing workout history records.

This enhancement demonstrates skills in mobile application development, Java programming, XML layout design, SQLite database integration, activity navigation, user input validation, testing, debugging, and software design.
